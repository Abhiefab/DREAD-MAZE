# DREAD MAZE

## Project Overview

DREAD MAZE is a 3D maze escape game developed using Unity and C#. The game challenges players to navigate through a complex maze, overcome moving wall obstacles, and find the exit before the countdown timer runs out.

Players begin at the starting point of the maze and must carefully explore the pathways to discover the correct route to the exit. The maze contains moving walls that act as obstacles, requiring players to observe their movement, identify openings, and find the right moment to pass through.

Time management, navigation, and quick decision-making are essential to completing the challenge.

## Game Objective

The main objective is to find a way out of the maze and reach the designated exit before the available time expires.

Players must navigate through the maze, avoid obstacles, identify safe passages, and make their way towards the endpoint.

## Gameplay Features

- 3D Maze Environment: Explore a maze with interconnected pathways and challenging routes.
- Third-Person Character Controller: Navigate the environment using a third-person player character.
- Moving Wall Obstacles: Overcome moving walls that block pathways and create additional challenges.
- Gap Navigation: Observe obstacle movement and find openings to pass through safely.
- Countdown Timer: Complete the maze before the time limit expires.
- Start Menu: Begin the game from the main menu.
- Pause Menu: Pause gameplay, resume the game, restart the level, or exit.
- Win Condition: Reach the designated endpoint to successfully complete the maze.

## Game Objective and Conditions

### Winning Condition

Navigate through the maze, avoid the moving wall obstacles, and successfully reach the END location before the countdown timer reaches zero.

### Losing Condition

If the countdown timer reaches zero before the player reaches the exit, the mission is unsuccessful.

## Gameplay Flow

1. Launch the game and select Start from the main menu.
2. Enter the maze at the designated starting point.
3. Explore the pathways and identify the correct route.
4. Observe moving walls and find suitable gaps to pass through.
5. Avoid obstacles while managing the remaining time.
6. Reach the END location before time expires to win.

## Game Menus

### Main Menu

### Pause Menu

During gameplay, players can access the pause menu to resume the game, restart the level, or exit.

## How to Run the Project

1. Clone or download this repository.
2. Install Unity Hub and a compatible Unity Editor version.
3. Open Unity Hub.
4. Select Add Project from Disk.
5. Choose the downloaded DREAD MAZE project folder.
6. Open the project in Unity.
7. Open the main game scene and press Play to start.
